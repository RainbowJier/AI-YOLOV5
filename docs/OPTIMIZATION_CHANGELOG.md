# 移动算法优化日志 (v3.1)

## 日期
2026-10-28

## v3.1 修复：鼠标不动了

v3.0 的弹簧追踪一个**模拟准星位置**（`_gx/_gy`），隐含假设"注入的
dots 让画面精确移动预测的像素"——开环。任何偏差（lock_sen 不准、
画面不响应、驱动问题）都会让模拟准星"先到达"而真实准星没动 →
输出衰减为 0 → **鼠标死住**。

v3.1 删除位置状态，每轴只保留一个**弹簧速度**，由当帧**实测误差**
驱动（半隐式积分，无条件稳定）：

```
v'  = (v + dt·ω²·e) / (1 + 2ω·dt)     临界阻尼
e   = 实测误差（死区内为 0）
out = v·dt（v 过 tanh 软限幅）
```

构造性闭环：画面不响应 → 误差不缩 → v 顶到限幅继续推，永远不会
"自认为已到达"。灵敏度偏差只会降低收敛速度，不可能卡死。

## v3 为什么重写（v2 的晃动根源）

v2 的抖动根源（仿真复现并确认）：

1. **前馈绕过死区**：`move = frac·chase + world_v·dt` 中 `world_v·dt`
   不经过死区和误差门。锁定后检测噪声 ±1-2px 被 ÷dt 差分（放大约 60 倍）
   成假速度，直接注入鼠标 —— 持续晃动。
2. **EMA 滤波不足**：`track_tau=0.019` 在 60fps 下只滤掉 ~41% 噪声，
   瞄准点本身就带 ±1.5px 抖动。
3. **粘滞半径太小**：`closest()` 25px 按框中心粘滞，近距时头/身框中心
   差超过 25px，每帧在两个框之间翻转 → 垂直大幅晃。

## v3 核心思想

```
模拟准星 = 追踪"门控后瞄准点"的临界阻尼弹簧
```

- 检测框 → EMA（`track_tau`）→ 吸收检测抖动
- 世界速度前馈带**噪声门**（`lead_min_speed`，默认 30px/s）：
  低于门限引导**严格为 0**，静止目标物理上不可能被前馈晃动
- 径向死区（`deadband_px`）：死区内弹簧目标 = 准星 → 硬保持，输出精确为 0
- **临界阻尼弹簧**（Unity SmoothDamp 数学）：任意输入都无过冲，
  弹簧内部速度状态自行衰减到 0 —— 环路里没有任何放大噪声的环节
- tanh 软限速（`max_move_speed`）：大修正滑入，不瞬移
- 粘滞选择 + 35% 迟滞：头/身框不再翻转
- 按住左键：吸附加速 3.0/2.6×（与 v2 一致；v3.1 曾短暂改成完全
  停用，实战中造成"识别到但鼠标不动"，已回退）

v2 的每一条晃动路径都被关闭：前馈进不来（速度门）、误差项进不来
（死区）、混合器本身已不存在。

## v3.0 与 v2.0 的参数对照

| 参数 | v2 | v3 | 变化 |
| --- | --- | --- | --- |
| `move_rate` | 指数收敛率 | 弹簧刚度（×speed） | 语义变，推荐值不变 |
| `track_tau` | 框 EMA | 框 EMA | 不变 |
| `deadband_px` | 软死区（缩放 chase） | 硬死区（死区内零输出） | 更强的噪声免疫 |

| `lead_min_speed` | — | 引导噪声门（px/s） | 新增 |
| `max_move_speed` | tanh 限速 | tanh 限速 + 弹簧限幅 | 不变 |
| `velocity_tau` | 速度 EMA | 世界速度 EMA | 不变 |

## 调节指南

| 症状 | 动作 |

## 附：v2.0 日志（已被 v3 取代）

## 改进内容

### 1. **架构重构** (零逻辑变更)

原单体 `aim_at()` 拆分为三个职责明确的模块：

- **`_update_track_state()`** — 追踪更新
  - EMA 平滑检测框位置
  - 双速度模型更新（frame-relative + world）
  - 目标重新获取逻辑（跳跃检测、超时检测）

- **`_compute_aim_point()`** — 瞄准点计算
  - 速度预测引导（EMA 延迟补偿）
  - 邻近衰减（减少锁定时抖动）
  - lock_y 应用

- **`_compute_move()`** — 鼠标移动输出
  - 错误分数 + 世界速度前馈混合
  - 死区处理
  - 软上限 (tanh) 防瞬移

### 2. **平滑度完全可调**

新增 config 参数：

```python
# 平滑：EMA 时间常数，越大越稳，越小跟得越紧
track_tau = 0.0250

# 速度预测平滑（内部常数，暴露出来）
velocity_tau = 0.060

# 吸附死区：锁定范围内不动鼠标
deadband_px = 2.5

# 引导衰减半径：预测衰减区间
lead_fade_radius = 12.0
```

**调节指南:**

| 场景 | track_tau | move_rate | deadband_px | 手感 |
|------|-----------|-----------|-------------|------|
| 竞技 (紧跟) | 0.015-0.025 | 8-10 | 1.0-1.5 | 快速反应，可能抖 |
| 平衡 | 0.030-0.040 | 6-8 | 2.0-2.5 | 标准 |
| 休闲 (柔和) | 0.045-0.060 | 4-6 | 3.0-5.0 | 平滑稳定 |

### 3. **吸附程度独立控制**

三个参数各司其职：

- `move_rate` → **快慢** (5-10)
- `track_tau` → **跟紧度** (0.015-0.060)
- `deadband_px` → **抖动过滤** (1.0-5.0)

**不是单一"吸附强度"，而是三维调节空间**，满足不同玩家偏好。

### 4. **代码可维护性**

- 每个函数 ≤ 30 行，职责单一
- 显式中间变量（chase_dist, deadband_scale, fade）
- 易于后续优化（自适应增益、方向性死区、低通滤波）
- 函数签名清晰，易于单元测试
