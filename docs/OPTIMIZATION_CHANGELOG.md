# 移动算法优化日志 (v2.0)

## 日期
2026-10-27

## 改进内容

### 1. **架构重构** (零逻辑变更)

原单体 `aim_at()` 拆分为三个职责明确的模块：

- **`_update_track_state()`** — 追踪更新
  - EMA 平滑检测框位置
  - 双速度模型更新（frame-relative + world）
  - 目标重新获取逻辑（跳跃检测、超时检测）

- **`_compute_aim_point()`** — 瞄准点计算
  - 速度预测引导（EMA 延迟补偿）
  - 邻近衰减（减少锁定时抖动）
  - lock_y 应用

- **`_compute_move()`** — 鼠标移动输出
  - 错误分数 + 世界速度前馈混合
  - 死区处理
  - 软上限 (tanh) 防瞬移

### 2. **平滑度完全可调**

新增 config 参数：

```python
# 平滑：EMA 时间常数，越大越稳，越小跟得越紧
track_tau = 0.0250

# 速度预测平滑（内部常数，暴露出来）
velocity_tau = 0.060

# 吸附死区：锁定范围内不动鼠标
deadband_px = 2.5

# 引导衰减半径：预测衰减区间
lead_fade_radius = 12.0
```

**调节指南:**

| 场景 | track_tau | move_rate | deadband_px | 手感 |
|------|-----------|-----------|-------------|------|
| 竞技 (紧跟) | 0.015-0.025 | 8-10 | 1.0-1.5 | 快速反应，可能抖 |
| 平衡 | 0.030-0.040 | 6-8 | 2.0-2.5 | 标准 |
| 休闲 (柔和) | 0.045-0.060 | 4-6 | 3.0-5.0 | 平滑稳定 |

### 3. **吸附程度独立控制**

三个参数各司其职：

- `move_rate` → **快慢** (5-10)
- `track_tau` → **跟紧度** (0.015-0.060)
- `deadband_px` → **抖动过滤** (1.0-5.0)

**不是单一"吸附强度"，而是三维调节空间**，满足不同玩家偏好。

### 4. **代码可维护性**

- 每个函数 ≤ 30 行，职责单一
- 显式中间变量（chase_dist, deadband_scale, fade）
- 易于后续优化（自适应增益、方向性死区、低通滤波）
- 函数签名清晰，易于单元测试
